# 5. MOTION DESIGN & INTERACTIONS

This is extremely important.

I want the website to feel like a premium Framer website.

Use motion purposefully.

### Page transitions
- Smooth entrance transitions.
- Subtle opacity and position changes.
- Consistent motion timing.

### Scroll interactions
- Scroll-triggered section reveals.
- Gentle parallax on selected images.
- Image reveal animations.
- Text stagger animations.
- Subtle background transitions.

### Hover interactions
- Image scale transitions.
- Underline animations.
- Elegant button interactions.
- Navigation hover states.
- Card image transitions.

### Micro-interactions
- Custom cursor effects only where appropriate.
- Animated scroll indicator.
- Smooth gallery navigation.
- Elegant loading states.
- Form validation animations.
- Newsletter success state.

### Motion rules
- Use Framer Motion / Motion where appropriate.
- Keep animation performance smooth.
- Avoid excessive movement.
- Support prefers-reduced-motion.
- Do not delay important content visibility.
- Respect mobile performance.

The experience must feel fluid, not distracting.
